# LeetCode 刷题记录

## 项目结构

```
Leetcode/
├── README.md        # 题目索引（按分类）+ 刷题日志
├── mycode/          # 日常练习（普通题）
├── 好题/            # 精选好题（值得反复刷）
└── 经验/            # 学习路线与经验笔记
```

- **mycode/**：日常刷题练习，随刷随记。
- **好题/**：精选好题，按 LeetCode 官方题型归类，值得反复刷。
- **分类体系**：一级按主题（`数组 / 链表 / 树 / 哈希表 / 字符串 / 栈与队列 / 动态规划 / 回溯 / 位运算 / 数学`），二级按清晰子题型细分（如 `数组/二分查找`、`链表/双指针`、`树/二叉搜索树`）。mycode 与 好题 共用同一套命名。
